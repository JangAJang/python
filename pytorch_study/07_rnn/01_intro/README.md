# pytorch_study/rnn

RNN(순환 신경망) 및 시계열 학습 노트. `pytorch_study/`의 하위 주제.

- 핵심 파일:
  - `intro.ipynb` — RNN 개념 소개
  - `basics.ipynb` — RNN 기본 구조/사용법
  - `hihello.ipynb` — hihello/charseq 하이퍼파라미터 실습
  - `longseq.ipynb` — 긴 시퀀스 학습 실습
  - `time_series.ipynb` — 시계열 예측 실습
- 리소스: `img/` — 노트북에서 참조하는 구조도/설명 이미지
- 연관: `pytorch_study/` 상위 폴더, 루트 `README.md` Phase 5 (RNN / 시퀀스 모델) 체크리스트

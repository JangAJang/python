# pytorch_study

PyTorch 딥러닝 학습 노트 — 텐서 기초부터 CNN(VGG/ResNet)까지. 리포에서 가장 큰 폴더이며 주제별로 노트북 파일이 늘어나는 구조.

- 핵심 파일(대표):
  - `tensor_manipulation.ipynb`, `linear_regression.ipynb`, `logistic_regression.ipynb`, `softmax_classification.ipynb` — 기초
  - `mult_layer_perceptron.ipynb`, `batch_normalization.ipynb`, `dropout.ipynb`, `weight_initialization.ipynb` — MLP 관련
  - `convolution.ipynb`, `mnist_cnn.ipynb`, `vgg.ipynb`, `res_net.ipynb` — CNN
  - `self_qna.md` — ChatGPT/구글링 기반 셀프 Q&A 모음 (예: CNN vs Transformer)
- 하위 폴더:
  - `rnn/` — RNN/시계열 학습 노트 (별도 [README](rnn/README.md) 참고)
- 리소스(모두 `.gitignore` 대상, 노트북 실행 시 자동 생성/다운로드): `MNIST_data/`, `cifar10/`, `custom_data/`, `model/`, `images/`
- 연관: 없음 (독립 실습 모음)

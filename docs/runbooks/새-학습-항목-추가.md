# 런북: 새 학습 항목 추가하기

목적: 새로운 알고리즘 풀이(leetcode) 또는 학습 노트(pytorch_study 등)를 리포에 추가할 때.

## 수정할 파일 (순서대로)

### A. 알고리즘 문제 풀이 (leetcode)
1. `leetcode/YYYY_MM_DD.ipynb` (또는 `.py`) — 오늘 날짜로 새 파일 생성, 문제 풀이 코드 작성
   - 참고: `leetcode/2026_03_09.ipynb`
2. `README.md` — 필요 시 Phase 10 "포트폴리오 & 실전" 등 관련 체크리스트 갱신

### B. 학습 노트 (pytorch_study)
1. `pytorch_study/<NN_phase>/<MM_주제명>/` — 새 주제 폴더 생성, 아래 3파일 세트 채우기
   - `concept.md` — 이론 정리 (한 줄 요약 · 핵심 개념 · 원리/수식). 참고: `pytorch_study/08_transformer/01_attention/concept.md`
   - `example.ipynb` — 최소 예제 (교재 스타일 토이 데이터)
   - `practice.ipynb` — Kaggle/LeetGPU 등 실제 데이터셋 실습, 첫 셀에 검증된 링크 + 문제 정의 명시. 참고: `pytorch_study/02_regression/01_linear_regression/practice.ipynb`
   - 이미지/도표가 필요하면 같은 폴더의 `img/` 하위에 추가
2. `README.md` — 해당 Phase 표에 한 행 추가: `| 진도(✅/⬜) | 주제 | [concept](/경로/concept.md) | 핵심 내용 | [practice](/경로/practice.ipynb) · 링크 |`
   - 참고: 기존 Phase 표(예: Phase 5 RNN 섹션)의 행 형식을 그대로 따를 것
   - 진도/링크는 이 표가 유일한 관리처 — 다른 문서(폴더 README 등)에 중복 기재하지 않는다

## 실행

- 노트북: Jupyter로 열어 셀 단위 실행 (해당 폴더가 cwd가 되어야 상대경로 `pd.read_csv(...)` 등이 동작)
- 스크립트: `python3 <path>.py`를 **해당 폴더 안에서** 실행

## 검증

- 노트북 전체 셀이 에러 없이 실행되는지 확인 (Restart & Run All)
- `git status`로 의도한 파일만 추가/변경됐는지 확인 (`.gitignore` 대상 데이터 폴더가 실수로 포함되지 않았는지)

## 흔한 함정

- 리포 루트에서 스크립트를 실행해 상대경로 CSV/데이터를 못 찾는 경우 — 반드시 해당 폴더로 이동 후 실행
- `README.md` 체크리스트 갱신을 잊는 경우 — 과거 커밋에서도 종종 생략되지만, 진행 현황판 역할을 하므로 가능하면 함께 갱신

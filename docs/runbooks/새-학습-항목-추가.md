# 런북: 새 학습 항목 추가하기

목적: 새로운 알고리즘 풀이(leetcode) 또는 학습 노트(pytorch_study 등)를 리포에 추가할 때.

## 수정할 파일 (순서대로)

### A. 알고리즘 문제 풀이 (leetcode)
1. `leetcode/YYYY_MM_DD.ipynb` (또는 `.py`) — 오늘 날짜로 새 파일 생성, 문제 풀이 코드 작성
   - 참고: `leetcode/2026_03_09.ipynb`
2. `README.md` — 필요 시 Phase 10 "포트폴리오 & 실전" 등 관련 체크리스트 갱신

### B. 학습 노트 (pytorch_study 등 주제별 폴더)
1. `<주제_폴더>/<주제명>.ipynb` — 새 노트북 생성 (예: `pytorch_study/rnn/<주제>.ipynb`)
   - 이미지/도표가 필요하면 같은 폴더의 `img/` 또는 `images/` 하위에 추가
2. `README.md` — 해당 Phase 체크리스트에 `- [x] <항목> ([링크](/경로/파일.ipynb))` 형식으로 추가
   - 참고: 기존 Phase 2, 3 항목의 형식을 그대로 따를 것

## 실행

- 노트북: Jupyter로 열어 셀 단위 실행 (해당 폴더가 cwd가 되어야 상대경로 `pd.read_csv(...)` 등이 동작)
- 스크립트: `python3 <path>.py`를 **해당 폴더 안에서** 실행

## 검증

- 노트북 전체 셀이 에러 없이 실행되는지 확인 (Restart & Run All)
- `git status`로 의도한 파일만 추가/변경됐는지 확인 (`.gitignore` 대상 데이터 폴더가 실수로 포함되지 않았는지)

## 흔한 함정

- 리포 루트에서 스크립트를 실행해 상대경로 CSV/데이터를 못 찾는 경우 — 반드시 해당 폴더로 이동 후 실행
- `README.md` 체크리스트 갱신을 잊는 경우 — 과거 커밋에서도 종종 생략되지만, 진행 현황판 역할을 하므로 가능하면 함께 갱신
